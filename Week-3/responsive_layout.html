Main Content

This is the main content area. On desktop screens, it appears as the larger column on the left, taking up two-thirds of the available width. On mobile screens (below 768px), it stacks vertically above the sidebar.

The responsive layout is achieved using CSS Flexbox combined with a media query. The container uses display: flex for the horizontal layout, and the media query switches it to flex-direction: column for mobile devices.
